# Map data

`naturalearth.json` is built from Natural Earth (https://www.naturalearthdata.com), which is in the public domain:
the 1:110m admin 0 countries (outlines and names) and the 1:50m populated places (name, longitude, latitude, country, population),
with coordinates rounded to 0.1 and 0.01 degrees. Every map cut-in carries the credit "Made with Natural Earth".
